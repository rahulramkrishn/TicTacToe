# 4. P009 Architectural Goal

P009 must establish the **Application Layer as the orchestration boundary** between external adapters and the Domain.

The target architecture should conceptually be:

```text
             API / UI / External Adapter
                       │
                       ▼
              Application Layer
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   Use Cases       DTOs/Models    Interfaces
        │
        ▼
       Domain
        │
        ▼
   Domain Events
        │
        ▼
 Application Event Handling
        │
        ▼
 Infrastructure
```

The Application layer must coordinate use cases without moving domain business rules out of the Domain.
