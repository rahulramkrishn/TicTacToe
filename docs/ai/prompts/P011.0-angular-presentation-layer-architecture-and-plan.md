# P011.0 — Angular Presentation Layer Architecture & Implementation Plan

## Objective

Establish the architectural design, component breakdown, reactive state management, and implementation plan for Phase P011 — Angular Presentation Layer for the TicTacToe assessment.

This is a **PLANNING GATE ONLY**.
Do NOT implement Angular components or application code during this phase.

---

## 1. Architectural Boundary

```text
Angular UI (Presentation Adapter)
    │
    │ HTTP only (JSON / ProblemDetails)
    ▼
REST API (TicTacToe.Api — P010.2)
    │
    ▼
Application Layer (TicTacToe.Application — P009)
    │
    ▼
Domain Layer (TicTacToe.Domain — P001–P008)
```

The frontend is strictly a **dumb presentation layer and reactive consumer**:
- **Zero Business Logic**: The frontend must NOT reproduce game rules, win detection, computer strategy, undo logic, scoreboard calculations, or event behavior.
- **Backend Authority**: All state mutations and game progress are driven exclusively by the backend API via HTTP. The frontend receives authoritative `GameStateDto` and `ScoreboardDto` responses and renders them.
- **Canonical Cell Addressing**: The frontend communicates solely in `cellIndex` (`0..8`). Grid coordinates (row/column) are derived strictly as a presentation concern.

## 3. Reactive State Management via Angular Signals (`GameFacade`)

Per `docs/05-architecture.md` §4, NgRx is intentionally avoided in favor of a clean, lightweight, native Angular 21 Signal-based facade (`GameFacade`):
- Holds reactive state signals (`_gameState`, `_scoreboard`, `_loading`, `_error`).
- Exposes derived computed signals (`board`, `currentPlayer`, `status`, `winner`, `winningCells`, `moveHistory`, `canUndo`, `isGameOver`).
- Exposes action methods (`initGame`, `playMove`, `undo`, `resetGame`, `resetScoreboard`, `dismissError`).
- Catches HTTP error responses and maps RFC 7807 `ProblemDetails` to user notifications.

## 4. Design System & Aesthetics (Premium UI)

- Deep slate/indigo dark theme palette.
- Glassmorphic card surfaces with subtle border glows.
- Vibrant accents: Electric cyan for X (`#38bdf8`), coral rose for O (`#f43f5e`), emerald for winning cells (`#10b981`).
- Modern typography via Google Fonts (Outfit / Inter).
- Micro-animations: cell hover lift, mark stamp-in, winning line pulse glow.
- Full keyboard and ARIA accessibility.
