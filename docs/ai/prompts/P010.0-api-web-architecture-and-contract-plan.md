# 3. Frozen Architectural Decisions

The following decisions are already frozen and MUST NOT be changed during P010 planning unless the existing repository proves that a prior implementation violates the specification.

## Cell addressing

The API uses:

```text
cellIndex: 0..8
```

Do NOT introduce:

```text
row/column
```

as an alternative addressing mechanism.

The API contract must remain consistent with this decision.

---

## Game ID

`gameId` identifies the logical game/session.

`Game.Reset()` reuses the existing `gameId`.

A new completed playthrough after reset generates a new domain-event `EventId`, while retaining the same `GameId`.

Do not introduce a new game ID during reset.

---

## Patterns

Existing architectural patterns must remain intact:

* **Memento Pattern** â€” snapshot-based undo
* **Strategy Pattern** â€” computer move selection
* **Domain Event Pattern** â€” `GameCompleted`
* **Aggregate Root** â€” `Game`
* **Aggregate Root** â€” `Scoreboard`
* Repository abstraction
* Application Service orchestration

The API layer must consume these capabilities rather than reimplement them.
