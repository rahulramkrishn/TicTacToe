## 3. Frozen Architectural Decisions for P009

1. **Pure Domain Boundary**: `TicTacToe.Domain` has 0 PackageReferences and 0 ProjectReferences. `IGameRepository` is defined in `TicTacToe.Domain.Repositories`.
2. **Transport Neutrality**: `TicTacToe.Application` has zero dependencies on `Microsoft.AspNetCore.Mvc` or HTTP status codes.
3. **Canonical Cell Indexing**: `cellIndex: 0..8` is strictly enforced.
4. **Event Lifecycle Ownership**:
   - `Game` aggregate creates and stores domain events.
   - `GameService` application use case dispatches events via `IDomainEventDispatcher`.
   - `Scoreboard` is updated via `GameCompletedEventHandler`.
   - `game.ClearDomainEvents()` is invoked only upon successful dispatch.
   - Failed dispatch leaves events pending on `Game` for retry.
5. **Reset Identity**: `Game.Reset()` preserves `GameId` (FR-12).
6. **In-Memory Storage**: `InMemoryGameRepository` uses `ConcurrentDictionary<GameId, Game>` with singleton lifetime.
