## 2. Reconciled Architectural Boundaries

### 2.1 Preserving the Application Layer Contract
P010 strictly consumes the existing Application layer abstractions created and verified in P009:
- `IGameService`
- `IScoreboardService`
- `GameStateDto`
- `MoveDto`
- `ScoreboardDto`
- `CreateGameCommand`
- `MakeMoveCommand`

The API layer does **not** create alternative internal DTO representations. Request models in `TicTacToe.Api.Models` (`CreateGameRequest`, `MakeMoveRequest`) exist strictly as transport-binding objects that map directly into Application commands:

```text
HTTP Request (JSON)
       ↓
API Transport Request DTO (e.g., MakeMoveRequest)
       ↓ (Controller maps to)
Application Command (e.g., MakeMoveCommand)
       ↓
Application Service (IGameService)
       ↓
Domain Aggregate (Game)
```

Controllers never touch domain entities or domain collections directly.

## 3. Frozen HTTP REST Contract

All routes are prefixed with `/api/`.

### 3.1 Endpoint Specifications

#### 1. Create Game
- **Method & Route**: `POST /api/games`
- **Request Body**:
  ```json
  {
    "mode": "TwoPlayer"
  }
  ```
  *(Mode is optional; defaults to `"TwoPlayer"`. Allowed: `"TwoPlayer"`, `"Computer"`)*
- **Success Status**: `201 Created`
- **Headers**: `Location: /api/games/{gameId}`, `Content-Type: application/json`
- **Response Body**: Authoritative `GameStateDto`

#### 2. Get Game
- **Method & Route**: `GET /api/games/{gameId}`
- **Parameters**: `gameId` (Guid formatted string)
- **Success Status**: `200 OK`
- **Response Body**: Authoritative `GameStateDto`
- **Error Status**: `404 Not Found` (ProblemDetails) if `gameId` does not exist
- **Invariant**: Strictly side-effect free.

#### 3. Make Move & Player Authority
- **Method & Route**: `POST /api/games/{gameId}/moves`
- **Parameters**: `gameId` (Guid formatted string)
- **Request Body**:
  ```json
  {
    "player": "X",
    "cellIndex": 4
  }
  ```
- **Player Authority Decision (Directive 1)**:
  - `player` is **client-supplied** in `MakeMoveRequest` per `docs/06-api-contract.md`.
  - However, **`Game.CurrentPlayer` remains strictly authoritative**. The client cannot dictate or override turns.
  - If the client supplies a `player` that does not match `Game.CurrentPlayer`, Domain throws `InvalidTurnException`, mapping to `409 Conflict` (`INVALID_TURN`).
- **Cell Index Rule**:
  - `cellIndex` strictly integer `0..8`.
  - Rejects `row` and `column` with `400 Bad Request` (`MALFORMED_REQUEST`).
- **Success Status**: `200 OK`
- **Response Body**: Authoritative `GameStateDto` (in Computer mode, contains both human and computer moves)
- **Error Statuses**:
  - `400 Bad Request` (`INVALID_CELL_INDEX`, `MALFORMED_REQUEST`)
  - `404 Not Found` (`GAME_NOT_FOUND`)
  - `409 Conflict` (`CELL_OCCUPIED`, `INVALID_TURN`, `GAME_ALREADY_COMPLETED`)

#### 4. Undo Move
- **Method & Route**: `POST /api/games/{gameId}/undo`
- **Parameters**: `gameId` (Guid formatted string)
- **Request Body**: Empty
- **Success Status**: `200 OK`
- **Response Body**: Authoritative `GameStateDto` (1 move reverted in TwoPlayer, 2 moves in Computer mode)
- **Error Statuses**:
  - `404 Not Found` (`GAME_NOT_FOUND`)
  - `409 Conflict` (`CANNOT_UNDO` — when history is empty or game is completed per Option A)

#### 5. Reset Game
- **Method & Route**: `POST /api/games/{gameId}/reset`
- **Parameters**: `gameId` (Guid formatted string)
- **Request Body**: Empty
- **Success Status**: `200 OK`
- **Response Body**: Authoritative `GameStateDto`
- **Invariants**:
  - **Preserves existing `gameId`** (FR-12).
  - Resets board, current player to `X`, status to `InProgress`, clears history.
  - Drains and dispatches pending domain events before resetting.
  - Preserves session scoreboard.

#### 6. Get Scoreboard
- **Method & Route**: `GET /api/scoreboard`
- **Success Status**: `200 OK`
- **Response Body**: `ScoreboardDto` (`{"xWins": 0, "oWins": 0, "draws": 0, "totalGames": 0}`)
- **Invariant**: Strictly side-effect free.

#### 7. Reset Scoreboard
- **Method & Route**: `POST /api/scoreboard/reset`
- **Request Body**: Empty
- **Success Status**: `200 OK`
- **Response Body**: `ScoreboardDto` with zeroed counters
- **Invariants**:
  - Resets `xWins`, `oWins`, `draws` to 0.
  - Preserves deduplication history (`_processedEventIds`).
  - Does NOT modify active game aggregates.

#### 8. Health Check
- **Method & Route**: `GET /health`
- **Success Status**: `200 OK`

## 4. Frozen JSON & Error Specifications

### 4.1 Unknown Property Handling (Directive 2)
- Configure `System.Text.Json` with `JsonUnmappedMemberHandling = JsonUnmappedMemberHandling.Disallow`.
- Any request containing unrecognized JSON properties (e.g. `"row"`, `"column"`, or arbitrary extra fields) fails deserialization with `JsonException`.
- Mapped to **`400 Bad Request`** with error code **`MALFORMED_REQUEST`**.

### 4.2 ProblemDetails Schema & Type URI Convention (Directive 4 & 5)
All API errors return RFC 7807 `ProblemDetails` with `Content-Type: application/problem+json`:

```json
{
  "type": "https://api.tictactoe.com/errors/cell-occupied",
  "title": "Cell Occupied",
  "status": 409,
  "detail": "Cell 4 is already occupied.",
  "instance": "/api/games/7d8a9f.../moves",
  "code": "CELL_OCCUPIED",
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
}
```

- **Type URI Convention (Directive 4)**: `https://api.tictactoe.com/errors/{code-kebab-case}`.
- **Trace ID Correlation (Directive 5)**:
  - Uses `Activity.Current?.Id ?? HttpContext.TraceIdentifier`.
  - Correlates incoming `traceparent` or `X-Correlation-Id` header if present.
  - Emits `X-Correlation-Id` response header and populates `"traceId"` in ProblemDetails payload.

### 4.3 Precise Exception-to-HTTP Mapping (Directive 3)
Broad `ArgumentException` mapping is removed. Only explicit client-input errors produce `400 Bad Request`. Internal argument failures fall through to `500 Internal Server Error`.

| Exception Type | Layer | HTTP Status | Code String | Title | Type URI |
|---|---|---|---|---|---|
| `GameNotFoundException` | Application | `404 Not Found` | `GAME_NOT_FOUND` | `Game Not Found` | `https://api.tictactoe.com/errors/game-not-found` |
| `InvalidCellIndexException` | Domain | `400 Bad Request` | `INVALID_CELL_INDEX` | `Invalid Cell Index` | `https://api.tictactoe.com/errors/invalid-cell-index` |
| `JsonException` / Deserialization error | ASP.NET | `400 Bad Request` | `MALFORMED_REQUEST` | `Malformed Request` | `https://api.tictactoe.com/errors/malformed-request` |
| `CellOccupiedException` | Domain | `409 Conflict` | `CELL_OCCUPIED` | `Cell Occupied` | `https://api.tictactoe.com/errors/cell-occupied` |
| `InvalidTurnException` | Domain | `409 Conflict` | `INVALID_TURN` | `Invalid Turn` | `https://api.tictactoe.com/errors/invalid-turn` |
| `GameAlreadyCompletedException` | Domain | `409 Conflict` | `GAME_ALREADY_COMPLETED` | `Game Already Completed` | `https://api.tictactoe.com/errors/game-already-completed` |
| `CannotUndoException` | Domain | `409 Conflict` | `CANNOT_UNDO` | `Cannot Undo Move` | `https://api.tictactoe.com/errors/cannot-undo` |
| All other exceptions (including internal `ArgumentException`) | Any | `500 Internal Error` | `INTERNAL_SERVER_ERROR` | `Internal Server Error` | `https://api.tictactoe.com/errors/internal-server-error` |

### 4.4 Unknown Exceptions Security Policy
- Emits HTTP 500 with generic client-safe message: `"An unexpected error occurred. Please try again later."`.
- **Zero stack traces, internal type names, or implementation details exposed in HTTP response.**
- Full exception details logged server-side with structured `TraceId`.

## 6. Dependency Injection Registration & Lifetime Plan

| Interface / Service | Concrete Implementation | Lifetime | Verification & Lifetime Rationale |
|---|---|---|---|
| `IGameRepository` | `InMemoryGameRepository` | **Singleton** | Maintains live authoritative in-memory game state across HTTP requests. |
| `IScoreboardRepository` | `InMemoryScoreboardRepository` | **Singleton** | Maintains session scoreboard aggregate across HTTP requests. |
| `IComputerMoveStrategy` | `BasicComputerMoveStrategy` | **Singleton** | Stateless pure domain strategy. |
| `IDomainEventDispatcher` | `DomainEventDispatcher` | **Singleton** | Synchronous in-process event router; registers `GameCompletedEventHandler`. |

| `IScoreboardService` | `ScoreboardService` | **Singleton** | Stateless application service delegating to singleton scoreboard repository. |
